# VigClean 0.0.2

VigClean 0.0.2 is a major product and safety update.

## Highlights

- Completely redesigned native SwiftUI interface with dedicated Clean, Apps, Disk, and History areas.
- Deterministic progress bars, exact completion percentages, current path details, and cancellable scans.
- Deletion Safety Engine that validates normal and administrator deletion paths.
- Recoverable cleanup through the macOS Trash by default.
- Persistent Protected List for folders that must never be removed.
- Cleanup history with processed bytes, recovered disk space, item counts, and errors.
- Expanded developer, browser, application, messaging, installer, and disk analysis coverage.
- Redesigned professional app icon and refreshed project documentation.
- Signed automatic updates from GitHub Releases using Sparkle 2.9.6 and EdDSA verification.

## Install

Download the Universal DMG for most Macs. Apple Silicon and Intel-specific packages are also provided.

Documentation: https://vigclean-guide.netlify.app
